# CAP004: observational metrics and honest field prediction probes

Statistics reads operate on a clone; dynamics owns telemetry/history updates. The change restores the CAP003 observational-metric repair when porting NFD onto its older default branch. NSF's LONG_RANGE_FRAC/REWIRE setting now enters the calibrated local/global connection-kernel mixture, so topology controls have an actual effect.

ATS is unavailable without external pre-feedback novel-task target scores. Previous-task mutual information no longer gets labeled novel-task competence. A separately named completed-task dynamics ratio is not an intelligence score. Existing intrinsic composite telemetry must not be advertised as validated capability.

`prequential.mjs` enforces predict-before-observe and supports a frozen holdout. It is a supervised external readout probe, not a learned native field algorithm or a capability label. Three-seed experiments with/without field plasticity score predictions after feedback is revealed: field-feature readouts remain near 50% binary accuracy, while a short-history readout reaches 72.3%. Plasticity has not demonstrated an external benefit here.

Run `node research/cap004/probe.mjs` with Node 24+. Three-seed purity, topology and pre-novel guards, plus prequential-order/frozen-holdout checks, passed. The public NFD change contains no private NSF source; each repository contains only its own field results.
